A local-first wireframe board with AI-native parts. One export hands your coding agent the picture and the exact spec behind it.

Open the app Self-host / install
1

Sketch

Drop components on the board. Chat, prompt bar, thinking trace, task list, approval card: parts drawn for agents, not generic boxes.

2

Export

One click produces a rendered PNG plus a written spec: every component's exact position, size, and content.

3

Build

Open in Claude Code, Cursor, or ChatGPT with the prompt already filled in. Paste the image, review, send.

Stop describing layouts in paragraphs.

The old loop with a coding agent is a chat full of corrections. With a wireframe, you send the picture once and it builds what you meant.

Without Wireframe
With Wireframe

The spec is the point.

A screenshot alone makes the agent guess. Wireframe exports the picture and the exact component list behind it (types, positions, sizes, labels), so the build lands on the first try.

  • Claude Code, Cursor, and ChatGPT open pre-filled
  • Nothing auto-sends. You review, then confirm
  • Or copy the two pieces into anything else

Your canvas, your call.

Four canvas tones from Midnight to Paper, with a dots or lines grid when you want structure. Every component re-renders for light canvases; the chrome stays out of the way.

  • Two darks, two lights, one click between them
  • Components adapt to the canvas, not just the chrome
  • Exports follow the tone you picked

Wireframe-first, as a skill.

Install the companion skill and your coding agent learns when a request is too vague to build from, and asks if you want to sketch it first. It knows when not to ask, too:

  • Fires only on genuinely ambiguous UI layout work
  • Silent on fixes, tweaks, and anything with a reference attached
  • One line, non-blocking, once per task
What your agent says
"Want to wireframe the layout first? Takes a minute and I'll build to the exact spec. Happy to just go for it otherwise."
and it stays quiet on fixes, tweaks, and anything with a reference already attached.

One file. Run it anywhere.

The whole app is a single self-contained HTML file with no build step, no account, and no telemetry. It installs as a PWA and works offline.

Use it

  1. Open wireframe-local.vercel.app. Or clone the repo and open app/index.html straight from disk.
  2. Your board autosaves locally. Add it to your dock or home screen as an app.

Install the agent skill

  1. Works unchanged in Claude Code, Codex, Cursor, and Aside.
  2. Easiest: the skills CLI auto-detects your agents and puts it in the right place:
npx skills add hedayatnia/wireframe --skill wireframe-first
  1. Manually: ~/.claude/skills/wireframe-first/ for Claude Code, ~/.codex/skills/wireframe-first/ for Codex, or add it as an account skill in Aside.
